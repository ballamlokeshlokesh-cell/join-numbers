# Join Numbers

A small browser-based matrix traversal game where the player follows the numbered spiral path in order.

## How to play

1. Open `index.html.html` in a browser.
2. Choose a difficulty:
   - Easy
   - Medium
   - Hard (Hidden Mode)
3. Click the numbers in ascending order from 1 upward.
4. Complete the spiral path to clear the level.
5. Use the level slider or number field to jump between levels.

## Features

- 100 levels
- Spiral matrix generation
- Difficulty-based grid sizing
- Hidden mode for harder play
- Level progression with restart and next-level controls

## Files

- `index.html.html` — complete game HTML, CSS, and JavaScript

## Run locally

Open the file directly in any modern browser:

```bash
open index.html.html
```

Or double-click the file in your file explorer.
